# Waypoint Motion Builder

각 웨이포인트에서 6개 출력축(MD0·1·2·6·7·8)의 목표각(deg), 구간 길이(ms),
가감속 파라미터를 입력해 `motion_NN.csv`와 `motion_NN.memo.json`을 생성합니다.

```bash
cd ~/Downloads/main/motion_builder
./motion_builder.py
```

생성물은 `library/<MS Name>/`에 저장됩니다. 프로젝트 JSON은 웨이포인트를 나중에
다시 편집하기 위한 파일이며 PCM에는 복사하지 않습니다.

## 엔드이펙터 위치로 웨이포인트 만들기

GUI의 `엔드이펙터 월드 절대좌표 → 조인트 각도`에는 1번팔과 2번팔 입력줄이 동시에
표시됩니다. 각 줄에서 X/Y/Z(mm), 팔꿈치 해를 설정하고 `IK → 각도`를 누릅니다.
계산된 값은 해당 팔의 세 축 각도 입력란에
들어가며, `추가`를 눌러야 실제 웨이포인트가 됩니다. 우측 3D 뷰에는 양팔 링크 자세와
웨이포인트 사이의 예상 조인트 공간 보간 경로가 표시됩니다.

3D 뷰는 ARM A를 `J1/J2/J3=phact0/1/2`, ARM B를
`J1/J2/J3=phact8/6/7`로 색상 구분하고 각 관절에
phact 번호를 표시합니다. 두 팔의 로컬 X축은 서로를 향하도록 배치됩니다. `두 J1 간격`
값은 시각화용 베이스 중심 간 거리이므로 실제 장착 간격(mm)을 측정해 입력하십시오.
3D 화면에서 마우스 왼쪽 버튼을 드래그하면 방위각·고도가 바뀌고, 휠로
`0.35×~3.5×` 확대/축소할 수 있습니다. 왼쪽 버튼을 더블클릭하면 기본 시점으로
돌아갑니다. 현재 방위각, 고도와 확대율은 화면 왼쪽 위에 표시됩니다.

좌표계는 두 팔 중심을 월드 원점으로 두며 X/Y는 공통 지면 좌표, Z는 지면 기준
절대 높이입니다. ARM A J1 지면점은 `(-간격/2, 0, 0)`, ARM B는
`(+간격/2, 0, 0)`에 있고 두 팔은 서로를 향합니다. 입력한 월드 좌표는 선택한 팔의
로컬 좌표로 자동 변환됩니다. `현재 각도 → 절대 EE`로 현재 입력각의 월드 위치를
확인할 수 있습니다. J2 축 높이 110.6 mm, J2~J3 100 mm,
J3~EE 끝점 120 mm를 사용합니다. PCM 출력각은 `profile.json`의 축별 부호와
`offset_deg`를 통해 기구학 각도로 변환됩니다.
실기구 검증 결과 ARM1의 J3인 `phact2`는 기구학 J3에 대해 반대 방향이므로
ARM1의 `sign`은 `[1, 1, -1]`입니다. ARM2의 J3인 `phact7`은 반대 방향이
아니므로 ARM2의 `sign`은 `[1, 1, 1]`입니다. 두 팔은 관절 구조가 같지만 모터의
출력 방향이 다릅니다.
버튼 1 준비자세와 연속되는 IK 해는 기본 `팔꿈치 -`입니다.
버튼 1 준비자세는 기구학 각도 `(J1, J2, J3)=(0°, 90°, -90°)`로 정의되어
J2~J3가 수직이고 J3~EE가 상대 팔을 향해 수평이 되며, 로컬 EE 좌표는
`(X,Y,Z)=(120, 0, 210.6) mm`입니다. 이 자세의 PCM 각도는 ARM A가
`(128.7, 105.3, 209.7)°`, ARM B는 J1/J2/J3 순서로
`(-129.1, 105.8, -210.1)°`입니다. ARM B의 물리 연결 순서가
`0x0A→0x08→0x09`이므로 phact 번호순과 관절 순서가 다릅니다.

`버튼 1 준비자세 입력`은 여섯 축 입력란을 이 값으로 되돌립니다.
`준비자세를 시작·끝에 추가`는 현재 경로 앞뒤에 동일한 준비자세 웨이포인트를 붙입니다.
중복으로 누르면 준비자세가 다시 추가되므로 웨이포인트 표를 확인해야 합니다.

실기구의 축 방향이 다르면 `profile.json`의 해당 그룹 `sign`을 `-1`로, 기구학 영점이
다르면 `offset_deg`를 조정해야 합니다. 시각화 경로는 충돌 회피 경로가 아니라 각도
웨이포인트 사이를 보간한 예상 경로입니다.

## SD카드 설치

SD카드를 쓰기 가능하게 마운트한 뒤 실행합니다.

```bash
./install_to_sd.sh library/CUSTOM_MOTION /media/phorce/9016-4EF8
```

기존 슬롯이 있더라도 사용자가 `OVERWRITE SLOT NN`을 정확히 입력하기 전에는 변경하지
않습니다. 확인 후 기존 CSV/memo를 생성폴더의 타임스탬프 백업 폴더에 보관하고 복사하며,
복사 후 바이트 비교까지 통과해야 성공합니다. 설치 후 `sync`하고 SD카드를 PCM에 장착한
뒤 PCM을 완전히 재시작해야 합니다.

GUI 상단의 `SD 마운트 경로`에서 SD카드를 선택하고 `현재 모션 SD에 쓰기`를 누르면
현재 화면의 웨이포인트로 CSV/memo를 자동 재생성한 뒤 설치합니다. 프로젝트 JSON만
저장하고 이전 CSV를 잘못 복사하는 것을 방지합니다.
새 슬롯은 예/아니요 확인 후 설치하며, 기존 슬롯은 `OVERWRITE SLOT NN`을 정확히
입력해야만 로컬 백업 후 덮어씁니다. CSV/memo 해시와 복사 결과도 검증합니다.
